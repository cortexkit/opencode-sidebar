# @cortexkit/opencode-sidebar

The shared OpenCode sidebar panel used by CortexKit plugins: a collapsible frame with a
header, stat rows, text rows, sections and the 10-cell bar, drawn with OpenTUI and Solid.

The frame is moving here from `@cortexkit/common-auth/quota-sidebar`. Until the first
release (0.1.0), keep using that subpath.
